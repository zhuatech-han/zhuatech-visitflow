## 当前机制

BCrypt12散列、12位强密码、30分钟HttpOnly/SameSite=Strict会话、CSRF、同源代理、按账号与IP的8次失败／5分钟登录限制。数据库每次业务查询实时角色和账号状态，停用或密码变化使会话失效。角色代码与有限业务动作在服务器注册，隐藏按钮不是安全边界。

访客列表、详情、事件快照、JSON导出、在场名单、统计和审计均检查权限与范围。没有访客匿名自助或公众查询。岗位目录只含显示名称和部门，不含登录名或密码。操作日志不记录访客载荷；业务事件作为受权限控制的记录保留。

## 部署责任

只收集接待所需姓名、单位和事由，不要求身份证、照片或电话；仍须由部署方确定告知、访问、保留与删除规则。没有一键个人信息匿名化或已提交记录硬删除。备份和导出包含访客数据，须保管并限制接触。不要将真实访客、内部地址、凭证或日志上传到源码平台。

外部部署须HTTPS、Secure Cookie、最小权限、数据库证书校验、备份恢复、监控、依赖更新和经授权的安全测试。单实例限速和会话不是分布式防护。未执行压力、渗透及生产合规认证；前台人工核对并不等同电子身份认证或门禁控制。

漏洞反馈请添加咨询微信说明安全漏洞反馈，在后续私密渠道提供细节；不要公开提交密码或可利用载荷。
